# Illure

## Sobre
**Illure** é um jogo 2D top-down desenvolvido em Godot Engine com foco em narrativa, exploração e ambientação.
O jogador percorre diferentes espaços interagindo com objetos do cenário, coletando pistas e conversando com personagens que ajudam a conduzir a história. A progressão acontece conforme objetivos são concluídos, revelando novos eventos e mudanças no ambiente.
A proposta de *Illure* é combinar exploração com narrativa visual, criando uma experiência guiada pela curiosidade do jogador e pelos detalhes espalhados pelo cenário.

## Desenvolvimento
O projeto foi desenvolvido em Godot utilizando GDScript e organizado em cenas, scripts e assets próprios integrados ao ambiente do jogo.
A lógica principal é controlada por um sistema global de etapas que gerencia a evolução da narrativa, objetivos ativos, diálogos, visibilidade de personagens e interações com objetos colecionáveis.
Além da parte técnica, o projeto também busca construir atmosfera através de pixel art, iluminação e elementos interativos distribuídos pelo mapa.
